# Code of Conduct

This is a small project, so this is a short document.

## What is expected

Be decent to each other. Assume the person on the other side is trying to help
and knows things you don't.

- Critique code, not people. "This threshold breaks on scanned pages" is useful;
  "this is amateur work" is not.
- Not everyone here shares your first language. This project is written by
  someone working in Spanish and documented in English on purpose. Awkward
  English in an issue or a pull request is not a defect, and neither is asking a
  question in Spanish.
- Not everyone here shares your level of experience. Beginner questions are
  welcome; a project about reading books is a bad place to be condescending
  about learning.
- Disagree, then accept the decision. Maintaining this is unpaid, so "no" is a
  complete answer and repeating the argument louder does not change it.

## What is not

Harassment, insults, discrimination on any grounds, sexualized language or
imagery, publishing other people's private information, and sustained
disruption. These get your comments removed and, if repeated, get you blocked
from the repository.

## Reporting

If someone is behaving this way, report it to the maintainer at
[github.com/dragon90o](https://github.com/dragon90o). Reports are handled
privately, and being the person who reported something will never be held
against you.

## Scope

This applies to issues, pull requests, discussions, commit messages and any
other space belonging to this project.
